Gestión de Riesgos y Decisiones Técnicas
Mitigaciones Arquitecturales
⚡ Importación Masiva Segura (CSV / Excel)
El parsing y la inserción masiva se ejecutarán en una sola transacción SQL atómica en Go, con validación previa de columnas para evitar estados inconsistentes.
🔒 Control de Cuotas en Middleware (Free vs Pro)
La validación de cuotas (límite de mesas, productos y sucursales) se aplicará a nivel middleware en la API Go antes de procesar las operaciones de escritura.
📊 Consultas de Métricas sin Impacto Operativo
Las métricas de ventas utilizarán índices compuestos en PostgreSQL (`tenant_id`, `created_at`, `status`) para garantizar tiempos de respuesta menores a 50ms.
